# 몰입형 비주얼 노벨 스타일 에이전트 도구

언제시작할진 모르지만 갑자기 재밌어보여서 미리 파둠, 리라이트 끝나거나 리라이트 하면서 머리식힐겸 와서 할듯

|기능예정|
|:----:|
|스트림 on/off|
|캐릭터 변경/추가|
|페르소나 변경|
|follow-up|

## follow-up 예시
- 기존의 앱들에서 쓰는거 그대로 선택지처럼 변경(ask_user, follow-up)

Q. 좋은 사과를 고르는법

A. 사과라... 그전에 몇가지만 물어볼게, 목적에 따라 좋은게 달라서 말이야.

A. 어떤 이유로 찾는데?

1. 사과주 만들려고
2. 그냥... 아픈사람이 있는데 병문안 국룰이니까
3. (입력창)
